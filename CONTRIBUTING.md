# Как вносить изменения

## Установка

```bash
python -m venv .venv
.venv/bin/pip install -e ".[dev]"        # Windows: .venv\Scripts\pip
```

## Перед коммитом

```bash
ruff format src tests
ruff check src tests
pytest -q
editor-team config validate
python .claude/skills/hs-edit/scripts/selftest.py
```

## Правило корпуса

`гайды/` — 49 опубликованных материалов. Это **тест-набор заведомо
хорошего письма**, а не данные для подгонки. Если новое правило начинает
на них срабатывать, правило ловит авторскую манеру, а не ошибку.

**Корпус не редактируется ради прохождения тестов.** Никогда.

## Как добавить проверку

1. Функция возвращает данные, а не печатает: иначе её не вызвать из
   `archive.py`, `selftest.py` и CLI.
2. Замерить на корпусе **до** того, как поверить в проверку.
3. Определить severity честно: `error` — только там, где есть
   авторитетный источник; эвристика — `likely`; спорное — `review`.
4. Добавить порог в `selftest.py`.
5. Добавить тест, который падал бы без исправления.

## Грабли, на которые уже наступали

- `pymorphy` возвращает разборы по вероятности; имя карты часто не первое.
  Всегда `C.lemmas()`, а не `parse(w)[0]`.
- Заглавная в начале предложения задана языком, а не автором.
- Заголовок и цитата — не проза, их регистр задан оформлением.
- Однословное имя карты совпадает со случайным словом: «К оружию!» ловит
  любое упоминание оружия.
- Нечёткое сравнение без общего корня выдумывает: «Сплоченных» ≈
  «Проклятие плоти».
- `.venv/bin/python` — симлинк на системный, `resolve()` делает пути
  равными. Сравнивать префикс окружения, а не пути интерпретаторов.
- В argparse подпарсер затирает значение родителя своим `None` —
  общие флаги объявляются с `default=SUPPRESS`.

## Стиль коммитов

Conventional Commits, одно логическое изменение — один коммит.
Не смешивать исправление, инфраструктуру и документацию.
