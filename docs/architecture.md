# Архитектура

```
config/                     единый источник правил
  terminology.yaml            решения по словам + частоты корпуса
  typography.yaml             ё, кавычки, дефис в архетипах, числа, тире
  profiles/*.yaml             жанры: разделы, анализаторы, веса

src/editorteam/             устанавливаемый пакет
  rules.py                    загрузчик и валидатор конфигурации
  profiles.py                 профили и автоопределение жанра
  finding.py                  модель находки, отчёт, exit code
  cli.py                      единый CLI поверх анализаторов

.claude/skills/hs-edit/     скилл Claude Code — пути не менялись
  scripts/                    анализаторы: markers, soul, rhythm, cards,
                              structure, consistency, echo, precedent,
                              archive, report, author, selftest
  assets/                     каталог маркеров, справочник карт
  references/                 справочники для редактора

tests/unit/                 pytest
docs/                       документация
гайды/                      корпус: 49 опубликованных материалов
```

## Границы модулей

**`config/` ничего не знает о коде.** Это данные: решение, основание,
частота. Markdown-документы ссылаются на конфигурацию и не дублируют
таблицы — расхождение между CLAUDE.md и ГОЛОС.md по «винрейту» случилось
именно из-за ручного дублирования.

**`src/editorteam/` не содержит анализаторов.** Он собирает их из скилла,
приводит результаты к общей модели и отдаёт человеку или в JSON. Так
скилл Claude Code продолжает работать сам по себе, без установки пакета.

**Анализаторы возвращают данные, а не печатают.** Печать живёт в `main()`
каждого скрипта и в `_emit()` CLI. Благодаря этому один и тот же анализ
идёт и в текстовый вывод, и в JSON, и в regression-прогон по корпусу.

**`common.py` — общая основа скилла:** пути, бутстрап `.venv`, морфология
с кэшем, разбиение текста, маскирование защищённых фрагментов. Пути
считаются в одном месте: раньше каждый скрипт считал сам и дважды ошибся
в числе уровней вверх.

## Совместимость

Старые команды работают без изменений:

```bash
python3 .claude/skills/hs-edit/scripts/markers.py текст.md
python3 .claude/skills/hs-edit/scripts/author.py текст.md
```

Новый CLI — дополнение, а не замена:

```bash
editor-team audit текст.md --profile battlegrounds-guide --format json
```

## Что где решается

| Вопрос | Где ответ |
|---|---|
| заменять ли слово | `config/terminology.yaml` |
| ё, кавычки, дефис, числа | `config/typography.yaml` |
| какие разделы обязательны | `config/profiles/*.yaml` |
| нормы корпуса (0,51 и 29,4) | `soul.py`, `rhythm.py` — рядом с формулой |
| что считать ошибкой, а что сигналом | `finding.py`, поле `severity` |
