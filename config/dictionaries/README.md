# Игровые словари

Эти файлы — allowlist для Hunspell. Здесь хранятся только устойчивые названия
и сленг, который редакция действительно оставляет в тексте. Словарь не
исправляет статью и не имеет приоритета над официальным названием карты.

Русский Hunspell-словарь (`ru_RU.aff` и `ru_RU.dic`) подключается отдельно
через `RU_DICT_PATH`; его файлы намеренно не копируются в репозиторий.
