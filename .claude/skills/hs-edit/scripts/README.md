# Инструменты правки

## Устройство

`common.py` — общая основа. Всё, что иначе копируется из скрипта в скрипт и разъезжается:

| Что | Зачем |
|---|---|
| `ROOT`, `CORPUS`, `ASSETS`, `SCRIPTS` | пути считаются один раз. Раньше каждый скрипт считал сам, и я дважды ошибся в числе уровней вверх |
| `ensure_venv("pymorphy3")` | единый перезапуск из `.venv`, если библиотеки нет в системном Python |
| `sibling("markers")` | подгрузка соседнего скрипта как модуля |
| `lemmas()`, `lemma_key()` | морфология с кэшем. Берёт **все** разборы слова: «Бранном» — это и «бранный», и «бранн», на первом разборе сверка карт один раз уже сломалась |
| `sentences()`, `paragraphs()`, `words()` | одинаковое разбиение текста во всех проверках |
| `card_db()`, `corpus_text()` | справочник и корпус с кэшем |
| `mask_protected()` | гасит код, цитаты, ссылки, коды колод |

Остальные скрипты делятся на три вида:

- **проверки одного текста** — `markers`, `rhythm`, `soul`, `cards`, `structure`, `consistency`
- **проверка публичной статьи** — `clarity` (роль игровых терминов, тезис и нагрузка текста; для аналитики также плотность служебных терминов и чисел)
- **работа с архивом** — `echo`, `precedent`, `archive`
- **сводка и надзор** — `report`, `selftest`

## Как добавить проверку

1. Новый файл рядом, первым делом:

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parent))
import common as C
```

2. Функции проверки принимают текст и возвращают данные, **не печатают**. Тогда их можно вызвать из `archive.py` по всему корпусу и из `selftest.py` в регрессии.

```python
def check_something(text):
    return Counter(...)          # данные, а не print
```

3. Печать — только в `main()`. Для единого вида есть `C.head()` и `C.hint()`.

4. **Замерить на корпусе до того, как поверить в проверку.** 49 гайдов — это вычитанный текст: если проверка ругается на них часто, ловит она авторскую манеру, а не ошибку. Так были сняты правило про парные тире (3915 ложных) и оборот «не только… но и» (147).

5. Добавить порог в `selftest.py`, чтобы находка аудита не протухла.

## Грабли, на которые уже наступали

- **Первый разбор слова врёт.** `pymorphy` возвращает варианты по вероятности; имя карты часто не первое. Всегда `C.lemmas()`, а не `parse(w)[0]`.
- **Заглавная в начале предложения ничего не значит.** Она задана языком, а не автором. Без учёта этого «Матч-апы» после точки считались разнобоем с «матч-апах» — 24 ложных находки на одном гайде.
- **Заголовок и цитата — не проза.** Их регистр задан оформлением. Гасить перед разбором написаний.
- **Однословное имя карты совпадает со случайным словом.** «К оружию!» ловит любое упоминание оружия, «Из глубин» — любой оборот. Требовать двух значимых слов или проверять частоту строчного написания по корпусу.
- **Перебор 6602 названий по каждому файлу — медленно.** Предфильтр по словам текста ускорил аудит архива с 42 секунд до 3,4.
- **Нечёткое сравнение без общего корня выдумывает.** «Сплоченных» превращалось в «Проклятие плоти». Требовать совпадения первых букв.

## Проверить, что ничего не сломано

```bash
python3 selftest.py
```

Валится, если правила начинают задевать опубликованные тексты: больше 20 срабатываний маркеров на 10 000 слов, меньше 20 живых сигналов на 1000 слов или распознавание структуры ниже 90%.
