# Скиллы разработки EditorTeam

Проектный набор импортирован из
[`Manacost-Labs/skills`](https://github.com/Manacost-Labs/skills) на ревизии
`dec9878a1f3d12a7c0a2a5b1419b146f07f2c847`.

Это намеренно небольшой профиль для гибридного Go/Python API-проекта. В него
вошли практики планирования, минимальных изменений, TDD, диагностики, ревью,
проверки результата, архитектуры, API-контрактов, документации, Git, CI,
Python-качества, производительности и работы с большим контекстом. UI,
WordPress, Next.js, мобильные и узкие браузерные скиллы не импортированы.

Корневой `AGENTS.md` перенесён полностью из той же ревизии. Более конкретные
правила EditorTeam из `CLAUDE.md`, `CONTRIBUTING.md`, `СТИЛЬ.md` и `ГОЛОС.md`
сохраняют приоритет в своей области. Системные, developer- и
security-инструкции всегда выше локальных правил и скиллов.

## Как выбирать скиллы

1. Сначала прочитать `AGENTS.md` и проектные правила.
2. Открыть `.agents/profile.yaml` и выбрать минимальный набор под задачу.
3. Прочитать выбранный `SKILL.md` полностью до изменения кода.
4. Применить только относящиеся к задаче проверки.
5. В итоговом сообщении назвать реально использованные скиллы и пропущенные
   проверки с причиной.

Наличие скилла не даёт дополнительных разрешений на секреты, production,
публикацию, удаление данных или другие опасные действия.

## Обновление

Обновления выполняются добавочно: сначала импорт в отдельную временную папку,
затем сравнение, проверка лицензий и только после этого замена проектной копии.
Локальный `better-writing` не перезаписывается этим набором.
