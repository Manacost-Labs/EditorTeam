# Черновик

Сегодня мы рады сообщить о по-настоящему важном обновлении, которое открывает новые возможности и выводит совместную работу на качественно новый уровень. В основе решения лежит стремление сделать процессы удобнее, быстрее и прозрачнее. Теперь команда может экспортировать отчёт в CSV из раздела «История запусков». Экспорт доступен владельцам рабочего пространства; данные за период свыше 90 дней в файл не попадают.
